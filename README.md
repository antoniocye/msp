# Sparse Concept Rare-Event Auditing

This repository contains a compact empirical study of whether a reusable sparse activation basis can reduce the label cost of rare-failure audits. The main report is [sparse-concept-rare-event-auditing-paper.md](sparse-concept-rare-event-auditing-paper.md).

The primary archived result is a CIFAR-10 run using a ResNet-18 backbone initialized from public ImageNet weights. The experiment asks whether an explanation-built estimator can compete with same-budget Monte Carlo sampling over a pre-specified distribution of rare failure predicates.

## Repository Layout

| Path | Purpose |
| --- | --- |
| `sparse-concept-rare-event-auditing-paper.md` | self-contained report |
| `sparse-concept-rare-event-auditing-references.bib` | references |

Downloaded datasets and local environments are intentionally ignored by git.

## Setup

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

The first run downloads datasets into `data/`.

## Reproduce The Archived CIFAR-10 Run

```bash
.venv/bin/python experiments/src/sparse_concept_rare_event_suite.py \
  --dataset cifar10 \
  --model-type resnet18 \
  --use-public-weights \
  --freeze-backbone \
  --seeds 20260521 \
  --train-n 6000 \
  --epochs 1 \
  --concept-calib-n 2500 \
  --build-n 6000 \
  --select-n 8000 \
  --ref-n 10000 \
  --risk-eval-n 6000 \
  --intervention-n 5000 \
  --pool-n 3072 \
  --query-count 12 \
  --max-candidates 1800 \
  --budgets 512 2048 \
  --reps 3
```

The script writes fresh outputs, including an autogenerated run report, to `experiments/results/sparse_concept_*`. The polished report in the repository root is not overwritten. The archived paper results are preserved under `experiments/results/stronger/cifar10_*`.

## Run The Decisive Benchmark

The stronger benchmark implements the external-query test proposed in the report discussion: many pre-registered rare predicates, multiple model and dictionary seeds, strong output/embedding/PCA/random/per-query baselines, and machine-readable support/disproof criteria.

```bash
.venv/bin/python experiments/src/sparse_concept_rare_event_suite.py \
  --datasets fashion_mnist cifar10 cifar100 \
  --model-type resnet18 \
  --use-public-weights \
  --freeze-backbone \
  --seeds 20260521 20260522 20260523 \
  --dictionary-seeds 0 1 2 \
  --train-n 12000 \
  --epochs 2 \
  --concept-calib-n 5000 \
  --build-n 12000 \
  --select-n 20000 \
  --ref-n 30000 \
  --risk-eval-n 12000 \
  --intervention-n 8000 \
  --pool-n 8192 \
  --query-count 100 \
  --max-candidates 20000 \
  --query-mode external \
  --budgets 64 128 256 512 1024 2048 \
  --reps 8 \
  --torch-threads 6 \
  --torch-inter-op-threads 1
```

The same command is recorded in `experiments/configs/decisive_external_benchmark.json`. The verdict table is written to `experiments/results/sparse_concept_verdict.csv`.

For a low-priority local run with thread caps, checkpoints, and logs:

```bash
scripts/run_decisive_external_benchmark.sh > experiments/results/decisive_external_benchmark.log 2>&1
```

The runner uses `BENCH_THREADS` if set; otherwise it uses `logical CPU count - 2`.

## Primary Result

At budget 512 labels per query, the sparse-internal estimator achieved an RMSE ratio of `0.561` relative to same-budget Monte Carlo over 12 rare-failure queries, with a bootstrap interval of `[0.433, 0.753]`. Including the one-time build labels, it crossed label-cost break-even after 5 audited queries in this run.
